# Security

Please report a vulnerability in sylva privately, by email to vabsgop@gmail.com or vabsgop@proton.me, with the subject
`[sylva] Security: <a short summary>`. Don't open a public issue for it.

Say what's affected (a version or commit), how to reproduce it, and what it lets an attacker do. You'll
get an answer, and the fix will credit you unless you'd rather it didn't.
