# Contact

Write to vabsgop@gmail.com or vabsgop@proton.me about sylva, with one of these subjects so it reaches the right place:

| For | Subject |
|---|---|
| A commercial license | `[sylva] Commercial license: <your company or product>` |
| Whether the royalty-free license covers you, or its attribution | `[sylva] Royalty-free license: <your question>` |
| A security problem (privately; see [SECURITY.md](SECURITY.md)) | `[sylva] Security: <a short summary>` |
| Anything else | `[sylva] <topic>` |

Bugs and feature requests go in the repository's issues.
